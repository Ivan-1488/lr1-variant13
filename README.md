# Лабораторная работа № 1. Вариант 13

## Задание

Разделить загруженное изображение на четыре части по вертикали и горизонтали, сохранить каждый фрагмент отдельным изображением и построить графики распределения цветов исходного изображения и каждого фрагмента.

## Реализовано

- Flask-приложение с HTML-формой загрузки изображения.
- Проверка пользователя: арифметическая CAPTCHA, honeypot-поле и минимальное время отправки формы.
- Допустимые форматы: PNG, JPG/JPEG, WEBP, BMP; лимит загрузки - 8 Мбайт.
- Разделение на четыре квадранта. Для изображений с нечётной шириной или высотой остаточный столбец/строка передаётся правым/нижним фрагментам, поэтому ни один пиксель не теряется.
- Для исходника и каждого фрагмента строится RGB-гистограмма с 256 значениями интенсивности каждого канала.
- Результаты хранятся в каталоге `static/results/<uuid>/`. Старые результаты автоматически очищаются через 24 часа.
- Тесты pytest проверяют разбиение, сохранение площади изображения, CAPTCHA, отклонение недопустимого формата и генерацию пяти гистограмм.

## Локальный запуск (Python 3.11)

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
export SECRET_KEY="replace-with-a-long-random-secret"
python app.py
```

Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
$env:SECRET_KEY = "replace-with-a-long-random-secret"
python app.py
```

Открыть `http://127.0.0.1:5000/`.

## Контрольный пример и проверка тестами

В каталоге `examples` находится тестовое изображение `demo_input.png`. Чтобы независимо проверить алгоритм без запуска HTTP-сервера, выполните из корня проекта:

```bash
python examples/run_demo.py
```

Результаты будут сохранены в `examples/generated`: исходное изображение, четыре фрагмента и пять RGB-гистограмм.

Полный набор тестов (включая HTTP-обработчики Flask) запускается после установки зависимостей:

```bash
pytest -q
```

## CI и размещение

При push и pull request workflow `.github/workflows/tests.yml` устанавливает зависимости и выполняет pytest. Для размещения на Render используется `render.yaml`; в качестве переменной окружения задаётся `SECRET_KEY` (в Render для неё включена генерация значения). Команда запуска: `gunicorn app:app --bind 0.0.0.0:$PORT`.

Файлы в `static/results` на файловой системе PaaS могут быть непостоянными после перезапуска экземпляра. В рамках лабораторной работы это допустимо: результат доступен после обработки в текущем экземпляре и автоматически удаляется по сроку хранения.

## Переменные окружения

| Переменная | Назначение | Обязательность |
|---|---|---|
| `SECRET_KEY` | Подпись сессии и CSRF-токена | Обязательно задать для развёртывания; локально есть временное значение по умолчанию |
| `PORT` | Порт веб-сервера | Необязательная, по умолчанию `5000` |

## Примечание по обработке

Координаты разреза вычисляются целочисленным делением `width // 2` и `height // 2`. Для нечётных размеров правый и нижний фрагменты получают дополнительный пиксель. Исходное изображение и результаты сохраняются в PNG; перед обработкой изображение нормализуется в RGB с учётом EXIF-ориентации.
